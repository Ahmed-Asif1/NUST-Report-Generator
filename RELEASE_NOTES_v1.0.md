# Academic Report Styler — v1.0 (Initial Release)

### 🚀 Highlights
- **Automated Academic Document Layout**: Converts unstructured lab manuals, homework sheets, and assignment briefs (.docx / .pdf) into structured Word document templates.
- **Multi-Discipline Profiles**: Built-in support for Computing (CS/SE/CE), Electrical & Electronics (oscilloscope waveforms, circuit schematics), Mechanical & Civil Engineering, Business Administration (SWOT tables, case analysis), and Humanities.
- **34 Dynamic Answer Blocks**: Context-aware generation of syntax-highlighted code blocks, command-line outputs, oscilloscope captures, mathematical calculation layouts, and reflection sections.
- **Local Web Dashboard**: Modern light/dark web user interface running 100% offline on local loopback (`http://127.0.0.1:8765`).
- **Privacy & Security**: Zero cloud dependencies or telemetry; device verification for authorized personal deployment.

---

### 📦 Setup & Usage
1. Download **`Academic_Report_Styler_v1.0.zip`** from the assets below.
2. Extract the archive to any folder on your PC.
3. Run **`NUSTReportGenerator.exe`**.
4. Enter your one-time activation password to bind the session to your device.
5. Your browser will automatically open the dashboard (`http://127.0.0.1:8765`).
